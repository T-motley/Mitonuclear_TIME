# Mitonuclear_TIME production assay
# A study of mitonuclear admixture effects on offspring production after evolution, specifically looking at:
#  1) does admixture affect production in cage evolved flies (F2 mismatched vs Fx matched)
#  2) does evolution restore any production differences after admixture (Fx mismatched vs Fx matched)
